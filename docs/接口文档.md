# S-DES 密码实验台接口文档

本文档描述可以被其他 Python 模块调用的稳定接口。接口不依赖 PySide6，适合编写测试、批处理工具或替代界面。

## 1. 导入方式

推荐从包根导入：

```python
from sdes_app import encrypt_block, generate_subkeys
```

也可以从具体模块导入，以便明确依赖来源：

```python
from sdes_app.core import encrypt_block
```

## 2. `sdes_app.core`

### `generate_subkeys(key) -> tuple[str, str]`

按作业要求的连续移位规则生成两个 8 bit 子密钥。

- `key: str`：10 bit 主密钥；
- 返回：`(k1, k2)`；
- 异常：类型不正确时为 `TypeError`，长度或字符不正确时为 `ValueError`。

```python
from sdes_app import generate_subkeys

k1, k2 = generate_subkeys("1010000010")
assert (k1, k2) == ("10100100", "01000011")
```

### `encrypt_block(plaintext, key) -> str`

加密一个 8 bit 明文分组，返回 8 bit 密文。

```python
from sdes_app import encrypt_block

ciphertext = encrypt_block("10111001", "1010000010")
assert ciphertext == "00000110"
```

### `decrypt_block(ciphertext, key) -> str`

解密一个 8 bit 密文分组，返回 8 bit 明文。解密轮密钥顺序为 `k2`、`k1`。

### `trace_encrypt_block()` / `trace_decrypt_block()`

返回不可变的 `CipherTrace` 数据对象，字段包括：

| 字段 | 含义 |
|---|---|
| `mode` | `encrypt` 或 `decrypt` |
| `input_bits` | 输入分组 |
| `key` | 主密钥 |
| `k1`, `k2` | 两个子密钥 |
| `first_subkey_name`, `second_subkey_name` | 两轮实际使用的子密钥名称 |
| `after_ip` | 初始置换结果 |
| `after_first_fk` | 第一轮 `fk` 结果 |
| `after_swap` | 交换左右半组后的结果 |
| `after_second_fk` | 第二轮 `fk` 结果 |
| `output_bits` | 最终输出 |

## 3. `sdes_app.text_cipher`

### `encrypt_ascii_text(text, key) -> TextEncryptionResult`

将 ASCII 文本按字节拆分，每个字节作为一个 8 bit 分组加密。结果对象提供：

- `plaintext`、`key`；
- `plaintext_bytes`、`ciphertext_bytes`；
- `block_count`；
- `ciphertext_hex`：空格分隔的大写十六进制；
- `ciphertext_binary`：空格分隔的 8 bit 二进制；
- `escaped_ciphertext`：连续的 `\\xNN` 表示。

### `parse_ciphertext(value, representation) -> bytes`

解析密文输入。

- `representation="hex"`：接受十六进制字节，可包含空格；
- `representation="binary"`：接受 8 bit 二进制分组，可包含空格或换行。

### `decrypt_ciphertext(ciphertext, key, representation="hex") -> TextDecryptionResult`

先按表示方式解析密文，再逐字节解密。结果对象提供 `plaintext_bytes`、`plaintext_display`、`is_ascii`、`plaintext_hex` 和 `plaintext_binary`。

## 4. `sdes_app.bruteforce`

### `parse_block_list(value, field_name) -> tuple[str, ...]`

将使用空格、逗号或换行分隔的多个 8 bit 分组解析为元组。`field_name` 只用于生成更明确的错误信息。

### `key_matches_pairs(plaintext_blocks, ciphertext_blocks, key) -> bool`

判断一个 10 bit 主密钥是否满足全部明文/密文分组对。两个序列按相同下标配对；该函数适合在自定义搜索策略或测试中复用。

### `brute_force_keys(plaintext_blocks, ciphertext_blocks, progress_callback=None) -> BruteForceResult`

遍历全部 1024 个 10 bit 主密钥，并返回满足所有明密文对的密钥。

- 两个分组序列数量必须相同；
- `progress_callback` 可选，签名为 `callback(checked_count: int)`；
- 返回 `matching_keys`、`checked_count`、`elapsed_seconds`。

```python
from sdes_app import brute_force_keys

result = brute_force_keys(
    ("10111001", "00000000"),
    ("00000110", "00001110"),
)
print(result.matching_keys)
```

## 5. `sdes_app.collision_analysis`

### `analyze_known_pair(plaintext, ciphertext) -> PairAnalysis`

分析单个 8 bit 明密文对，返回 `matching_keys` 和 `candidate_count`。

### `analyze_plaintext_collisions(plaintext, progress_callback=None) -> CollisionAnalysis`

固定一个明文，计算 1024 个主密钥产生的密文分布。返回对象提供：

- `ciphertext_to_keys`：密文到主密钥元组的映射；
- `multiplicity_histogram`：碰撞倍数统计；
- `reachable_ciphertext_count`：可达密文数量；
- `unreachable_ciphertext_count`：不可达密文数量；
- `collision_excess_keys`：超过不同密文数量的密钥数；
- `elapsed_seconds`。

### `analyze_key_equivalence() -> KeyEquivalenceAnalysis`

按 `(k1, k2)` 对主密钥分组，返回等价类。结果对象提供 `classes`、`class_count` 和 `class_size_histogram`。

## 6. 异常约定

| 异常 | 使用场景 |
|---|---|
| `TypeError` | 参数不是要求的字符串或回调类型 |
| `ValueError` | 长度错误、包含非法字符、分组数量不一致或表示方式不支持 |

调用者应在界面层捕获这些异常并转换为用户可读的提示；算法接口本身不显示弹窗，也不依赖 Qt。

## 7. 版本与兼容性

当前接口以项目源码为准，适用于 Python 3.10+。数据类使用不可变对象，调用者不应修改返回值；若需要改变输入，应创建新的字符串或序列后重新调用接口。
