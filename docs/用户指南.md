# S-DES 密码实验台用户指南

## 1. 文档目的

本指南说明安装、启动、五个关卡的操作方法、输入格式和常见问题。程序是 Python + PySide6 桌面应用，第二关属于组间交叉测试，不需要新增界面代码。

## 2. 安装与启动

### 2.1 环境要求

- Windows 10/11；
- Python 3.10 或更高版本；
- PySide6 6.8 或更高版本且小于 7；
- 建议使用项目目录下的独立虚拟环境，不与系统 Python 或 Anaconda 全局环境混用。

### 2.2 创建虚拟环境

在项目根目录 `D:\infosectest01` 打开 PowerShell：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

如果 PowerShell 阻止激活脚本，可以直接使用虚拟环境解释器安装和启动：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

PyCharm 中选择 `D:\infosectest01\.venv\Scripts\python.exe` 作为项目解释器即可。

### 2.3 启动和测试

```powershell
python main.py
python -B -m pytest -q -p no:cacheprovider
```

正常启动后窗口标题为“S-DES 密码实验台”，顶部提供第一关、第三关、第四关和第五关标签页。

## 3. 五个关卡的操作

### 3.1 第一关：基本测试

1. 在“数据分组”输入一个 8 bit 二进制字符串。
2. 在“主密钥”输入一个 10 bit 二进制字符串。
3. 点击“执行加密”或“执行解密”。
4. 右侧“输出结果”显示最终 8 bit 结果；“运算轨道”显示 IP、两轮 `fk`、SW、`IP⁻¹` 以及 `k1`、`k2`。

示例：

```text
数据分组：10111001
主密钥：1010000010
加密结果：00000110
```

解密时将 `00000110` 作为数据分组输入，可以恢复 `10111001`。输入框会检查长度和字符，不能包含除 `0`、`1` 以外的字符。

### 3.2 第二关：组间交叉测试

第二关不提供单独的程序标签页。三人小组应使用统一测试向量，交换可执行程序或结果，并比较：

- `P10`、`P8`、`IP`、`IP⁻¹`、`EP`、`SP`；
- 两个 S-Box，尤其是作业要求指定的 S-Box2；
- 连续移位生成 `k1`、`k2` 的规则；
- 加密和解密结果。

建议记录测试输入、对方小组、期望结果、实际结果和是否通过，作为提交材料中的交叉测试记录。

### 3.3 第三关：ASCII 文本加密与解密

1. 在顶部输入 10 bit 文本模式主密钥。
2. 在左侧输入 ASCII 文本，点击“执行文本加密”。
3. 左侧会显示十六进制密文、每字节 8 bit 二进制密文和转义字节。
4. 右侧选择“十六进制”或“二进制分组”。可以手动输入密文，也可以点击“使用左侧密文”。
5. 点击“执行文本解密”。

第三关只接受 ASCII 字符。换行、制表符等可显示控制字符会保留；不可直接显示的恢复字节会显示成 `\\xNN`，便于复制和检查。

### 3.4 第四关：暴力破解

1. 在“明文 P”和“密文 C”输入一组或多组 8 bit 分组。
2. 多组数据可以使用换行、空格或逗号分隔。
3. 明文和密文必须按顺序一一对应，数量相同。
4. 点击“开始破解”，程序遍历全部 `2^10 = 1024` 个主密钥。
5. 右侧显示搜索进度、耗时和满足全部明密文关系的候选密钥。

当前可复现实例：

```text
明文：10111001
      00000000
密文：00000110
      00001110
```

### 3.5 第五关：封闭测试

第五关包含三个分析区域：

1. **单对明密文候选**：输入一组明文和密文，列出满足该关系的全部 10 bit 主密钥。
2. **固定明文的密文分布**：固定一个明文，统计 1024 个主密钥产生的密文种类、碰撞数量和可达密文数量。
3. **等价密钥分析**：按 `(k1, k2)` 对主密钥分组，显示等价类数量和大小分布。

示例：

```text
明文：10111001
密文：00000110
```

分析过程中状态栏会显示“未开始”“分析中”或“完成”，避免误将旧结果当成当前输入的结果。

## 4. 输入规则速查

| 场景 | 格式 | 说明 |
|---|---|---|
| 第一关数据分组 | 8 位二进制 | 只能包含 `0` 和 `1` |
| 主密钥 | 10 位二进制 | 用于生成 `k1`、`k2` |
| 第三关文本 | ASCII 字符 | 每个字符独立作为一个 8 bit 分组 |
| 第三关十六进制密文 | 两位十六进制一组 | 空格可有可无 |
| 第三关二进制密文 | 8 位二进制一组 | 空格、换行可有可无 |
| 第四关、第五关分组 | 8 位二进制 | 多组用空格、逗号或换行分隔 |

## 5. 常见问题

**提示“必须恰好为 8/10 bit”**：检查是否多输入了空格、换行或其他字符；程序会去除首尾空白，但不会忽略字符串中间的非法字符。

**第三关解密结果出现 `\\xNN`**：这表示恢复字节不是可直接显示的 ASCII 字符，不代表程序异常。

**第四关没有候选密钥**：检查明文与密文是否一一对应，以及输入是否由同一套 S-DES 参数生成。

**如何恢复初始状态**：使用当前页面的“清空”按钮，再重新输入数据；切换标签页不会改变算法参数。
