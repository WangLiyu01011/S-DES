# 第三关测试说明

## 验收范围

第三关在第一关的单分组 S-DES 基础上增加 ASCII 文本模式：输入字符串按 1 Byte 分组，逐字节执行相同的 S-DES 加密或解密。


## 手工测试用例

主密钥统一使用：

```text
1010000010
```

### T301：ASCII 文本加密

输入：

```text
This is a test
```

预期：

- 字符数：14
- 密文分组数：14
- 十六进制密文：

```text
22 68 C7 27 62 C7 27 62 BD 62 4E F8 27 4E
```

- 二进制输出包含 14 组，每组 8 bit。

### T302：十六进制密文还原

将上面的十六进制密文粘贴到右侧，格式选择“十六进制（推荐）”，点击“执行文本解密”。

预期恢复：

```text
This is a test
```

### T303：二进制密文还原

将左侧二进制输出复制到右侧，格式选择“二进制分组”，点击“执行文本解密”。换行和空格都应被正确忽略。

### T304：非 ASCII 输入

输入中文或其他非 ASCII 字符，程序应提示：

```text
第三关文本模式只接受 ASCII 字符
```

### T305：密文格式校验

- 十六进制字符数量为奇数：提示必须由完整的两位字节组成。
- 出现 `G` 等字符：提示只能包含 `0-9、A-F`。
- 二进制长度不是 8 的整数倍：提示长度错误。
- 二进制中出现除 `0`、`1` 外的字符：提示格式错误。

## 自动化测试

在项目根目录执行：

```powershell
pytest -q
```

测试覆盖文本加密、十六进制解密、二进制解密、ASCII 校验、密文格式校验以及 GUI 文本模式操作流程。
