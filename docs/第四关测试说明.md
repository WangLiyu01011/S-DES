# 第四关测试说明

第四关依据作业要求的“暴力破解”要求实现：给定同一主密钥下的一组或多组明文/密文分组，遍历全部 10 bit 密钥空间，列出所有满足条件的候选密钥，并记录搜索耗时。

## 操作步骤

1. 运行 `python main.py`，切换到“第四关 · 暴力破解”。
2. 在“明文 P”和“密文 C”中输入 8 bit 二进制分组。每行一个分组，也可以使用空格或逗号分隔。
3. 明文和密文按照输入顺序一一对应，分组数量必须相同。
4. 点击“开始破解”，观察密钥空间进度条、已测试数量和耗时。
5. 破解结束后，在“候选密钥”区域查看全部匹配的 10 bit 密钥。

## 示例

输入：

```text
明文：10111001
密文：00000110
```

结果应包含作业示例密钥 `1010000010`。由于 S-DES 的部分密钥可能表现等价，单组明密文可能得到多个候选；增加明密文分组可以缩小候选范围，但如果仍存在等价密钥，程序会全部保留并提示。

## 计时与录制

程序从开始遍历前记录高精度时间，在完成 1024 个候选后显示总耗时。进度条和耗时标签会随破解过程更新，可以使用系统录屏或动图工具记录第四关过程。

## 自动化验证

```powershell
.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

测试覆盖密钥搜索、分组解析、数量校验，以及 GUI 中的输入和结果显示流程。
